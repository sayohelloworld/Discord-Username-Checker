# Discord Username Checker

A Python-based Discord username availability checker.

## Features

- Single username checking
- Multiple username checking
- Username format validation
- CMD interface
- Separate modules
- Credits section

## Installation

    py -m pip install -r requirements.txt

## Launch

    py main.py
